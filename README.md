## Publish with GitHub Pages

1. Create a public repository for the portfolio.
2. Upload `index.html`, `README.md`, and `.nojekyll` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, then select `main` and `/(root)`.
5. Save and wait for GitHub Pages to publish the site.

The portfolio includes a **Reflections & documentation** section for learning notes, project decisions, limitations, and lessons learned.
